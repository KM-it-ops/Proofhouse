# Proofhouse 0.8.0

Proofhouse now makes rules, MCP servers, hooks, and apps for every platform, and tries each one for real
before you get it.

```bash
pip install --upgrade proofhouse
```

## New

- **Rules, MCP servers and hooks.** `proofhouse make "..." --kind rule`, `--kind mcp` or `--kind hook`.
  A rule is installed and removed in every rule-capable tool using throwaway settings. An MCP server is
  started and asked for its tools. A hook is run on a sample event. Each comes with an install line or a
  settings snippet.
- **Apps for every platform.** `proofhouse make "..." --kind app --platform pwa --platform android ...`
  makes one shared web app plus a package for each platform: an installable web app (PWA), Windows, macOS,
  Linux, iOS and Android. Platforms are data: add your own in `PROOFHOUSE_HOME/app_platforms.json`.
- **`--allow-commands`.** Nothing a model wrote is started without it. Commands get a cleaned environment,
  a time limit, and a kill of everything they start. This is an opt-in, not a sandbox.
- **Required requirements.** `proofhouse evaluate-product --require-req ID` fails a run that misses a
  required requirement, and benchmarks can list `required_req_ids`.

## Fixed

- A failed install or update (disk full, file locked) keeps your existing settings and installed files as
  they were, with a clear error and nothing half-written left behind. Two runs saving the same file at
  once no longer collide.
- An app build cannot be faked: package install scripts do not run, a build output that was already
  there before the build fails the check, and a model-written project cannot use dotted folders, local,
  aliased or tarball packages, or its own lockfile. Capacitor and Tauri config files and settings that
  would run the model's own code are refused, and the build tool must come from its real package.
- Every run record names the Proofhouse version that made it.
- Rubric scoring is type-strict, compiler JSON inputs reject repeated keys, and very deep nesting is a
  clear error. Rubric matching now scores list, dict and null expected values as 0.0.
- The project scan never follows links, reads only regular files, cleans everything it prints, and
  redacts pasted private keys.
