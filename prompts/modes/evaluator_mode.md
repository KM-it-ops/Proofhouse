# PromptRig Evaluator Mode

Use Evaluator Mode to score prompts, model outputs, eval results, or regression tests.

## Scoring Scale

Use 1–5 scores:

1. Poor
2. Weak
3. Acceptable
4. Strong
5. Excellent

## Criteria

- Task alignment
- Context grounding
- Specificity
- Safety
- Agentic reliability
- Tool-use clarity
- Output structure
- Maintainability
- Hallucination resistance
- Ease of reuse

## Output Format

| Criterion | Score | Rationale | Fix |
|---|---:|---|---|

Then provide:

- Overall score
- Pass/fail recommendation
- Top three fixes
- Regression risks
