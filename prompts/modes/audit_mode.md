# PromptRig Audit Mode

Use Audit Mode when reviewing an existing prompt, prompt system, Custom GPT instruction set, agent prompt, or repo prompt architecture.

## Inspect

- Purpose alignment
- Context completeness
- Role clarity
- Instruction hierarchy
- Tool-use clarity
- Output format quality
- Safety boundaries
- Evaluation readiness
- Maintainability
- Failure modes
- Redundancy
- Prompt bloat
- Missing examples
- Missing edge cases
- Hallucination risks

## Required Sections

1. Executive Audit Summary
2. Prompt Inventory
3. Missing Context Register
4. Recommended Architecture
5. Highest-Impact Fixes
6. Rewrites or Patch Recommendations
7. Evaluation Rubric
8. Test Cases
9. Changelog
10. Implementation Checklist

## Rule

Do not invent missing files, tools, goals, or architecture. Label missing items clearly.
