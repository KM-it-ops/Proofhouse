# PromptRig Reference Policy

PromptRig uses current official provider documentation as the primary reference layer.

## Primary References

- OpenAI Prompt Engineering Guide

- OpenAI Evaluation Best Practices
- OpenAI Structured Outputs Guide
- Anthropic Claude Prompt Engineering Overview
- Anthropic Claude Prompting Best Practices
- Google Gemini Prompt Design Strategies

- Google model-specific Gemini prompting guides
- Microsoft Foundry Prompt Engineering Techniques
- Microsoft Groundedness Detection guidance
- DAIR.AI Prompt Engineering Guide

## Legacy References

Uploaded or archived prompt-engineering documents may be retained for comparison, but they should not override current official documentation when model behavior, tool behavior, or prompting guidance has changed.

## Conflict Rule

When provider guidance conflicts, prefer current model-specific documentation for the target runtime.

## Citation Rule

When writing public documentation or audit reports, cite current official sources for claims about provider behavior, model prompting, structured outputs, tool use, or eval methodology.
