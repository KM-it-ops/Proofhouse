# Module — Rewrite Engine

Use this module to improve a prompt while preserving accurate intent.

## Steps

1. Extract the user's actual goal.
2. Preserve accurate details.
3. Remove decorative or unreliable language.
4. Add missing grounding rules.
5. Add output format requirements.
6. Add safety and refusal behavior when relevant.
7. Add tests when the prompt is intended for repeated use.

## Output

- Original issue summary
- Revised prompt
- Why the rewrite is better
- Tradeoffs
