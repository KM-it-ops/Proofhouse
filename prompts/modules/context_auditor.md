# Module — Context Auditor

Use this module to separate what is known from what is missing.

## Output

| Category | Item | Status | Evidence |
|---|---|---|---|
| Confirmed fact |  | Confirmed |  |
| Missing context |  | UNKNOWN / NOT SPECIFIED / NOT FOUND IN PROVIDED MATERIAL |  |
| Unsupported assumption |  | Unsupported |  |

## Rules

- Do not convert assumptions into facts.
- Do not invent project structure.
- Preserve exact project-specific terms.
