# OAR-001 — Owner ratification of Compiler Core v0.1

**Status:** Accepted and binding  
**Ratified:** 2026-07-21  
**Owner authority:** Project Owner (identity not specified in provided material)  
**Mission:** MISSION-001A — Owner Ratification and Architecture Freeze Closeout

## Purpose and authority

This record captures the Project Owner explicit acceptance of five previously blocking decisions. It is an authorization record, not a replacement for an ADR or a new product specification.

The ADRs and compiler-freeze documents explain the reasoning, consequences, and implementation boundaries. This OAR establishes that the owner has accepted the listed decisions and that they are binding for Compiler Core v0.1.

## Ratified decisions

### OAR-001-01 — Authoritative runtime

Python 3.11+ is the authoritative Compiler Core v0.1 runtime and CLI implementation language. Generated JSON Schema and TypeScript contracts remain consumer artifacts; they are not a second compiler implementation.

### OAR-001-02 — Adapter order

The implementation order is deterministic fake adapter → OpenAI → Anthropic → Gemini. The fake adapter is the offline conformance reference. No provider may be silently substituted or downgraded.

### OAR-001-03 — Public IR version

PromptRig IR 0.1.0 is the first frozen public IR contract. Historical 0.2.0 schemas and documents remain preserved as noncanonical prototype history under the v0.4 review corpus.

### OAR-001-04 — Canonical hashing

Canonical hashing uses RFC 8785-style JSON Canonicalization Scheme (JCS), UTF-8 encoding, SHA-256, duplicate-key rejection, no implicit Unicode normalization, and rejection of invalid Unicode/lone surrogates. Canonicalization failures are diagnostics, never silent repairs.

### OAR-001-05 — Diagnostic registry

Diagnostic codes are assigned by one central immutable registry. Codes are never reused. Registry changes require reviewed changes and an ADR or an explicitly linked accepted decision. Retired codes remain reserved and must not be reassigned.

## Binding scope

These decisions are binding for Compiler Core v0.1, its public library, CLI, deterministic fake adapter, contract fixtures, and generated boundary artifacts. They do not freeze hosted jobs, tenant isolation, live-provider execution semantics, benchmark controls, billing, or deferred UI/PRS/MissionRig surfaces.
