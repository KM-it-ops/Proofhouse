# Dependency review — rfc8785 0.1.4

## Decision

Approved for MISSION-006 canonical JSON serialization and pinned exactly as
`rfc8785==0.1.4` in `pyproject.toml`.

## Purpose and source

- **Purpose:** implement RFC 8785/JCS byte serialization, specifically the
  ECMAScript-compatible IEEE-754 number algorithm that PromptRig must not
  reproduce with Python `repr()`.
- **Maintainer/source:** Trail of Bits; source repository
  `trailofbits/rfc8785.py`; PyPI package `rfc8785` 0.1.4.
- **License:** Apache License 2.0.
- **Runtime dependency posture:** pure Python with no transitive runtime
  dependencies. Development extras are not installed by PromptRig.

## Contract and security review

- The library emits deterministic UTF-8 bytes, orders object keys according
  to JCS, and implements the RFC 8785 IEEE-754 rendering algorithm.
- PromptRig retains its own duplicate-key and lone-surrogate rejection before
  delegation, performs no Unicode normalization, and wraps dependency errors
  in `CanonicalizationError` at the public compiler boundary.
- The dependency performs no I/O or network access. Input remains bounded by
  PromptRig's existing parsing and compiler controls; canonicalization errors
  fail closed.

## Alternatives considered

- **Continue the local serializer:** rejected; the audit demonstrated that
  Python `repr()` plus integral-float conversion disagrees with RFC 8785
  Appendix B.
- **Embed a new Ryu/ECMAScript port:** rejected for v0.1; it expands the
  security-critical surface and would require a separate algorithm audit.
- **Call Node/V8:** rejected; introduces an external runtime and breaks the
  compiler's self-contained deterministic Python deployment model.

## Verification

The regression suite decodes every finite RFC 8785 Appendix B IEEE-754 vector
from hexadecimal and asserts the exact canonical bytes. It also asserts hard
failure for NaN and both infinities.
