## Status vocabulary

- `SATISFIED_CURRENT`: evidence proves the requirement within a stated current scope.
- `PARTIAL`: some evidence exists, but a required stage or surface is missing.
- `PLANNED`: mapped to a roadmap phase with no current implementation claim.
- `DEFERRED`: intentionally blocked behind named dependencies.
- `PROPOSED`: owner ratification is still required.

## Traceability maintenance contract

Every implementation mission must map each in-scope requirement to contract clauses, code paths, positive/negative/adversarial tests, evidence outputs, and the roadmap exit gate. A row may not move to `SATISFIED_CURRENT` because a document mentions the capability or a schema accepts an instance.

A reviewer must block roadmap drift when any strategic law lacks a current evidence path, a major capability disappears from the roadmap without a deferred/rejected decision, a phase lacks entry/exit evidence, or implementation changes without a corresponding traceability update.
