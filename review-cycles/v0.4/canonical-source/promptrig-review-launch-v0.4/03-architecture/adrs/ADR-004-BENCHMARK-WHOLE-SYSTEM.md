# ADR-004-BENCHMARK-WHOLE-SYSTEM — Whole Agent Configuration as Benchmark Unit

**Status:** Accepted

## Context

Published evidence shows harness design can materially affect outcomes under fixed models.

## Decision

Identify results by model, harness, tool permissions, environment, routing, budgets, and intervention policy.

## Consequences

Marketing must not shorten a whole-system result into an unsupported model-only claim.

## Review trigger

Revisit when evidence materially changes the tradeoff, not merely because an implementer prefers another stack.
