# Roadmap

## Phase A — Foundation

Complete. Product constitution, scope, requirements, baseline architecture, security, UX, schemas, and benchmark specification exist.

## Phase B — Research and Design Review

Current phase. Conduct competitive research, independent specialist reviews, synthesis, ADR/RFC resolution, and architecture freeze.

## Phase C — Executable Benchmark Starter

Create monorepo scaffold, generated contracts, deterministic fake provider, migrations, container environment, CI, benchmark runner, public tests, telemetry, and evidence sealing.

## Phase D — Multi-Agent Build-Off

Run Codex, Claude Code, and Kimi Code from identical sealed commits. Execute repeated autonomous runs first, then separately disclosed steered runs.

## Phase E — Synthesis Alpha

Select or reimplement the strongest verified subsystem designs, reconcile provenance and licensing, rerun all tests, and launch a closed alpha.

## Phase F — Commercial Readiness

Complete security assessment, billing, managed credits and BYOK, operational controls, legal/licensing review, support processes, and evidence-backed public launch.
