# Implementation Entry Criteria

No coding-agent production build begins until:

1. architecture freeze is approved;
2. all P0 contracts and schemas validate;
3. the executable benchmark starter scope is fixed;
4. a deterministic fake provider is specified;
5. public and hidden test boundaries are defined;
6. environment versions and network policy are pinned;
7. required secrets and external accounts are documented without embedding credentials;
8. benchmark agents receive identical sealed starter commits;
9. telemetry and evidence capture are enabled;
10. rollback and rerun procedures are tested.

Spikes and disposable prototypes are allowed before freeze only when clearly labeled and excluded from benchmark submissions.
